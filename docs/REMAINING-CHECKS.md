- **2026-10-24 の方針 (公開の前提にしない。C++ / MFC の系統は、その系統の作業を再開するときに、まとめて確認する) を、引き継ぐ。** ホスト側ツールの確認 (H4、T8、T9、R 系、M 系) は、2026-10-24 に完了している。

- **確認していない項目を、✔ にしない。** 他の確認で、同じ点が実機で確認できた場合だけ、根拠 (TEST-PLAN の行) を書いて、✔ にする (H9 は、2-12 の HV4 の出力が根拠)。
- 小さく確認の項目 (H8・WF3・N4) は、2026-10-31 にすべて ✔。CT5 (2-15。ASP.NET Core で、どちらも選ばれない) は、任意で、未実施。
- **スキルの選択の確認 (CT 系) は、確認用のフォルダを、毎回、新しいパスにし、起動前にメモリが空であることを確かめる** (TEST-PLAN 2-15)。
